# Role guides - Uninvited

One guide per game-development role, written 2026-10-04 from nine role reviews (each reviewer researched the best practices
of its discipline and reviewed the build). `DESIGN.md` stays the source of truth: where a guide and `DESIGN.md` differ,
`DESIGN.md` wins. Update a guide when a decision in its area changes.

Each guide has the same parts: what the role owns, principles (with sources), decisions for Uninvited, rules of thumb and
metrics, the 2026-10-04 review with a status per finding, a release checklist, and don'ts.
