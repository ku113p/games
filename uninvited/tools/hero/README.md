# The hero model (H10)

`build.py` turns the Quaternius **Universal Animation Library 1 + 2** (CC0, "Standard" edition) into
`assets/models/hero.glb`: the H10 hero (`art/generated/H10-hero-hood.jpg`, DESIGN 14) with only the clips the game uses.
Everything on top of the Quaternius mannequin is generated by the script, so the model can be rebuilt and tweaked.

## Run

```sh
# the two packs, unzipped anywhere (the script searches the folder for UAL1_Standard.glb and UAL2_Standard.glb)
blender -b --python tools/hero/build.py -- --src ~/Downloads/quaternius
# options
#   --out <file.glb>     default assets/models/hero.glb
#   --preview <dir>      also renders Cycles stills (turntable + a few poses), ~1 min on a CPU
#   --blend <file>       saves the built scene for a look in Blender
```

Blender 4.5 (tested with 4.5.3 LTS). ~10 s without previews. The output is deterministic (seeded random).
Use the in-place `UAL*_Standard.glb` files, not the `_RM` (root motion) ones.

## What the glb contains

| Node / material | What | Used by `view/hero.ts` for |
| --- | --- | --- |
| `Body` (`Suit`, `SuitJoints`) | the Quaternius mannequin, 13.7k triangles | matte black suit |
| `SuitLines` (`NeonLines`) | ribbons traced on the body: outer leg to shin front, top-back of the arms, two chest lines | the hero color (ending counter) |
| `Coat` (`Coat`, `NeonLines`) | sleeveless long coat with a high collar, open at the front, two back seams in `NeonLines`; below 0.8 m it splits into tapering strips. Float attribute `_glow` (0 -> 1 toward the strip tips) | emissive glow of the strip tips |
| `Filaments` (`Filaments`) | 4 thin ribbons hanging from each strip; `_glow` 1 at the root -> 0 at the tip | additive fade + sway shader |
| `Hood` (`Coat`), `Visor` (`Visor`) | hood skinned to head / neck / chest; the glowing visor strip inside | visor color |
| `Wrist` (`Gun`, `Holo`, `NeonLines`) | band and hologram panel on the left forearm | flickers while hacking |
| `Gunblade` empty (child of `hand_r`) | sword grip; children `GunBody` (`Gun`, `NeonLines`), `Blade` (`Blade`), `Muzzle` empty | blade shown in sword mode, retracted in rifle mode |
| `RifleHold` empty (child of `hand_r`) | where `Gunblade` sits in rifle mode | the view blends the two transforms |
| bones `coat_{l,r}{1..4}_{a,b,c}` | 8 two-bone chains around the hips (parent `pelvis`), `c` is a leaf that marks where `b` points | swung at runtime: hang, trail, pushed out of the legs |

## Clips

| glb name | Source (pack) | How the view plays it |
| --- | --- | --- |
| `idle` | Idle_Loop (1) | idle, sword mode |
| `idle_rifle` | Pistol_Idle_Loop (1) | idle, rifle mode |
| `walk`, `run` | Walk_Loop, Jog_Fwd_Loop (1) | one phase-synced blend by speed (both start on the left foot) |
| `crouch_idle`, `crouch_walk` | Crouch_Idle_Loop, Crouch_Fwd_Loop (1) | blend by speed |
| `jump_start`, `jump_loop`, `jump_land` | Jump_Start, Jump_Loop, Jump_Land (1) | first 0.3 s in the air, then the loop; land after > 0.35 s in the air |
| `dash` | Sword_Dash (2) | the lunge part (20-62 %) over the 0.22 s dash |
| `slash_a`, `slash_b`, `slash_c` | Sword_Regular_A, Sword_Regular_B (2), Sword_Attack (1) | upper body; a -> b -> c combo within 1.1 s, eased so the strike lands early |
| `aim`, `shoot` | Pistol_Aim_Neutral, Pistol_Shoot (1) | upper body; the rifle stays raised 0.8 s after a shot, plus a gun kick |
| `hit` | Hit_Chest (1) | scrubbed by the core's action progress |
| `death` | Death01 (1) | once, held on the last frame |
| `hack` | Spell_Simple_Idle_Loop (1) | loop while the hacking mini-game is open |

Clip speeds measured from the `_RM` files (root motion per cycle): walk 1.3 m / 1.33 s (0.98 m/s), jog 5.0 m / 0.93 s
(5.36 m/s), crouch walk 1.5 m / 2.0 s. The constants at the top of `view/hero.ts` use these numbers.

## Changing things

- Shapes, sizes, line paths, hem length and strip count: the constants and functions in `build.py` (`GAP`, `Z_CUT`,
  `FLARE`, `LINE_THETAS`, `CHAINS`, `neon_lines()`, `build_hood()`, `build_gunblade()`...).
- A different clip: edit `CLIPS` (name in the glb, source name, pack). A new state also needs code in `view/hero.ts`.
- Colors and glow strength are set in `view/hero.ts` (the glb materials are replaced by name), not in Blender.
- The file is ~2.3 MB (no Draco, no textures, no UVs); the body mesh and 18 clips are most of it.
