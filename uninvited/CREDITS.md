The hero's look (hood, long coat with the strip hem and filaments, visor, neon lines, wrist display, the gunblade, the
extra coat bones) is generated by our own Blender script `tools/hero/build.py` on top of the Quaternius Universal Base Characters male body.
The script was written with Claude Code (Anthropic), 2026-10-04.
The warden's look (the faceted armor, the lantern helmet with its visor slit, the light lines, the chest core and the
wrist emitter) is generated by our own Blender script `tools/warden/build.py` on top of the Quaternius mannequin.
That script was written with Claude Code (Anthropic), 2026-10-04.
